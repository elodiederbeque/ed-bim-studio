# ED BIM Studio

Portfolio BIM professionnel d'Élodie Derbeque.

Ce site présente mon profil de modeleuse BIM, mon travail de fin d'études et le projet **ED BIM Starter**, un plugin Autodesk Revit développé en C# pour automatiser la structuration des projets BIM.

## Site en ligne

https://elodiederbeque.github.io/ed-bim-studio/

## Objectif

Mettre en avant un profil BIM orienté :

- modélisation Revit ;
- coordination BIM ;
- structuration de projets ;
- conventions de nommage ;
- automatisation Revit API en C# ;
- amélioration des workflows BIM.
